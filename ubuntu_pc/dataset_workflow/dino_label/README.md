# 📊 Dataset Annotation for YOLOv5 Using Grounding DINO

![Ubuntu](https://img.shields.io/badge/Ubuntu-20.04-orange.svg) ![Python](https://img.shields.io/badge/Python-3.8+-blue.svg) ![YOLOv5](https://img.shields.io/badge/YOLOv5-v7.0-brightgreen.svg)

This directory provides a pipeline for generating and refining annotations for YOLOv5 training datasets using **Grounding DINO**, a text-prompt-based object detection model. The pipeline automates initial bounding box annotations and supports manual refinement for higher accuracy, suitable for tasks like fruit detection in robotic applications. The generated annotations are stored in YOLO-compatible format, enabling seamless integration with YOLOv5 training workflows.

---

## 📖 Overview

The `dino_label` directory automates and refines dataset annotation for YOLOv5 by:
1. Preprocessing images to a uniform format and size.
2. Using **Grounding DINO** to generate initial bounding box annotations based on text prompts.
3. Allowing manual refinement of annotations for improved accuracy.
4. Splitting the dataset into training and validation sets.

This pipeline is designed for rapid dataset creation, balancing automation with manual control, and is particularly useful for fine-tuning YOLOv5 models for specific object detection tasks (e.g., detecting ripe fruits).

---

## 📂 Directory Structure

```bash
├── images/            # Stores input images for annotation
├── labels/            # Stores generated YOLO-format annotations
├── better_anno.py     # Script for manual refinement of annotations using OpenCV
├── data.yaml          # YOLOv5 dataset configuration file
├── labelling.py       # Script for automated annotation using Grounding DINO
├── png.py             # Script to convert images to PNG format
├── resize.py          # Script to resize images to a uniform size (e.g., 640x640)
├── train_val.py       # Script to split dataset into training and validation sets
├── README.md          # This documentation
```

- **`images/`**: Contains raw images to be annotated (e.g., photos of fruits).
- **`labels/`**: Stores YOLO-format `.txt` annotation files generated by `labelling.py` and refined by `better_anno.py`.

## 🚀 Annotation Pipeline

### Setup Instructions
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/mu9enn/eyes_piper.git
   cd eyes_piper/ubuntu_pc/dataset_workflow/dino_label
   ```

2. **Install Dependencies**:
   - Install YOLOv5 dependencies:
     ```bash
     cd ~/yolo_workflow/yolov5
     pip install -r requirements.txt
     ```
   - Install Grounding DINO:
     ```bash
     pip install -U git+https://github.com/IDEA-Research/GroundingDINO.git
     ```
   - Install OpenCV and NumPy:
     ```bash
     pip install opencv-python numpy
     ```

3. **Prepare Input Images**:
   - Place images to be annotated in the `images/` directory.
   - Ensure images are in a compatible format (e.g., JPG, PNG).

### Run Annotation Scripts
Navigate to the `dino_label` directory:
```bash
cd ~/yolo_workflow/dataset_workflow/dino_label
```

Run the scripts in the following order:

1. **Convert Images to PNG**:
   ```bash
   python png.py
   ```
   - **Function**: Converts all images in `images/` to PNG format for consistency.
   - **Output**: Overwrites or creates PNG images in `images/`.

2. **Resize Images**:
   ```bash
   python resize.py
   ```
   - **Function**: Resizes images in `images/` to a uniform size (e.g., 640x640) for YOLOv5 compatibility.
   - **Output**: Updates images in `images/` with resized versions.

3. **Automated Annotation with Grounding DINO**:
   ```bash
   python labelling.py
   ```
   - **Function**: Uses Grounding DINO to generate bounding box annotations based on a text prompt (e.g., "red pepper", "yellow pepper").
   - **Customization**: Modify the `TEXT_PROMPT` variable in `labelling.py` to match your target objects (e.g., `TEXT_PROMPT = "ripe fruit"`).
   - **Output**: Generates YOLO-format `.txt` files in `labels/` corresponding to each image.

4. **Manual Annotation Refinement**:
   ```bash
   python better_anno.py
   ```
   - **Function**: Uses OpenCV and NumPy to display images and allow manual adjustment of bounding boxes for improved accuracy.
   - **Usage**: Follow on-screen instructions to refine annotations interactively.
   - **Output**: Updates `.txt` files in `labels/` with refined bounding boxes.

5. **Split Dataset**:
   ```bash
   python train_val.py
   ```
   - **Function**: Splits images and annotations into training and validation sets, typically stored in `images/train/`, `images/val/`, `labels/train/`, and `labels/val/`.
   - **Output**: Organized dataset structure for YOLOv5 training.

## 🧠 Training YOLOv5 with Generated Data

### 1. Edit Dataset Configuration
The `data.yaml` file defines the dataset structure for YOLOv5 training. Example content (adjust paths and class names as needed):
```yaml
path: /home/sunx/code_proj/dataset_workflow/dino_label  # Dataset root directory
train: images/train  # Training images (relative to 'path')
val: images/val      # Validation images (relative to 'path')
test:                # Test images (optional)

# Classes
nc: 2                # Number of classes
names: ['immature', 'mature']  # Class names
```

If needed, create or modify `data.yaml`:
```bash
cd ~/yolo_workflow/dataset_workflow/dino_label
touch data.yaml
```

### 2. Run Training
```bash
cd ~/yolo_workflow/yolov5
python train.py --data ../dataset_workflow/dino_label/data.yaml --epochs 300 --weights '' --cfg yolov5s.yaml --batch-size 128
```
- **Output**: Training results are saved in `yolov5/runs/train/exp$num$/weights/`.
- **Usage**: Copy `best.pt` to `yolov5/` and update the weight path in `ros_detect.py` for detection.

## 📚 Usage Notes
- **Annotation Quality**: Grounding DINO provides automated annotations, but they may require refinement via `better_anno.py` for high accuracy, especially for complex scenes.
- **Customization**: Adjust the `TEXT_PROMPT` in `labelling.py` to match your target objects (e.g., "apple" instead of "pepper").
- **Image Size**: Ensure `resize.py` outputs 640x640 images, as this is the default input size for YOLOv5. Modify if using a different model configuration.
- **Manual Refinement**: Use `better_anno.py` to correct misaligned or inaccurate bounding boxes, especially for small or occluded objects.
- **Future Improvements**: The pipeline can be enhanced by integrating pre-trained detection or segmentation models (e.g., SAM or YOLO-World) to reduce manual effort in `better_anno.py`.
